# 使用说明

一套表情包分四步：**识别 → 风格设定 → 表情计划 → 生成与质检**，最后导出。每一步都可以停下来改，选「全自动」则一路跑完（批量生成前仍会停下来确认预计费用）。

## 1. 新建

- 上传 0–4 张图：拖拽、点击，或直接粘贴（⌘V）
- 不传图也行：按描述原创形象，或者做纯文字包
- 多张图时，建议在想法里写清每张的用途，例如「图1 是我的小猫，按图2 的风格做一套表情包」；没写清的由 AI 判断
- 每张图会被标成：主体 / 风格参考 / 主体+风格 / 元素场景参考 / 其他，识别页可以改。风格参考图只学画法，不会被当成主体
- 想要热梗就在想法里点名（如「加一张喝大水」），不点名不会自动加

## 2. 识别

AI 判断：

- **主体类型**：拟人动物、真实宠物、真人、双角色、物品、手势、纯文字
- **角色外貌**：纯文字包没有角色
- **语气**：软萌 / 嘴硬反差 / 淡人自嘲 / 轻度发疯 / 互怼 / 实用 / 喜庆，最多 2 个
- **3 个内容方向**：每个对应一个场景模板，包括日常、情侣、群聊、职场、卖货、亲友问候、节日、游戏

以上都可以改。

## 3. 风格设定

- 14 种风格，分角色插画、实拍字幕、文字装饰三组；上传了风格参考图时，还会多出「按参考图风格」
- 每种风格配一张原创样张，并标出 AI 推荐 / 备选 / 近期流行 / 与主体是否搭
- 点「预览」生成一张 2×2 风格设定图：左上是主体设定（纯文字包是字体样张），其余三格是示例表情
- 可以补一句风格要求再预览，多张并排对比，选中一张确认。后面每张表情都以它为参考

## 4. 表情计划

- 每条有情绪、画面描述、配字、循环动作，可以增删改，也可以写一句要求让 AI 重新策划
- **画面描述**只管静图，**循环动作**只管动图，两者分开
- 勾「动图」（或「全部直出动图」）的条目会**直出 GIF**：不先出静图，静图从动图中间一帧取

## 5. 生成与质检

- 多张并发生成，卡片上显示进度和自动质检提醒：没带上参考图、背景没去干净、主体贴边、主体偏小
- 卡片上：✓ 通过 / ✕ 打回 / ↻ 重画 / ⏹ 中断；顶部可以暂停队列、全部中断，额度用完会自动暂停
- 点开单张可以：
  - 改配字（叠加字的风格不重画）
  - 局部修改（以当前图为底稿）
  - 改描述重画（可以切换直出动图）
  - 做成 GIF（写循环动作，留空就按情绪自动设计）
  - 切换历史版本、锁定
- 「批量做动图」给还没有动图的表情一起做
- 换风格：回到「风格设定」选另一张，未锁定的表情会按新风格重画

## 6. 导出

- 打包已通过的表情（没有通过的则导出全部未打回的）
- 包里有 240×240、512×512 成品、封面 240、图标 50；动图另放 `gif-240/`、`gif-512/`
- 240 的动图超过 500KB 会自动降色
- 对应的情绪和配字在 `list.txt`

## 风格的几个开关

`server/styles.json` 可以自己增改，每种风格除了画风描述，还能设：

| 字段 | 作用 |
|---|---|
| `caption.mode` | `overlay` 后期叠字（可设字色 / 描边色），`model` 由画面直接画字 |
| `whiteBorder` | 主体外围加粗白色贴纸描边（默认禁止白边，避免深色模式里抠不干净） |
| `bgPalette` | 底色列表，按顺序轮换铺在圆角方块里 |
| `captionAnim` | `bounce`：动图里配字上下跳动 |

## 项目管理

- 每个项目是 `data/runs/<项目id>/` 一个文件夹，`project.json` 记录全部状态，旁边是原图、风格设定图、每个版本的图、动图和导出包
- 首页卡片「📁 目录」在系统里打开该项目；「归档」把整个目录移到 `data/archive/` 并从列表移除，「🗄 已归档」里可以恢复

## 代码结构

```
server/        本地服务（express）
  pipeline.mjs       流程编排与生成队列
  codex-service.mjs  Codex 订阅：出文字 / 出图
  api-backend.mjs    生图 API（兼容 OpenAI Images API）
  api-text.mjs       生文 API（Responses / Chat Completions）
  prompts.mjs        提示词与结构化输出 schema
  imaging.mjs        去背景、质检、配字合成、导出尺寸
  styles.json        风格预设
  style-guide.json   主体、语气、场景模板、近期热梗
web/           前端（React + Vite）
demo-video/    演示视频（Remotion）
poc/           早期验证脚本
```
